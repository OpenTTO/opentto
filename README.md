# OpenTTO

OpenTTO is a collaborative initiative for developing and sharing open,
reusable workflows, tools, software, and educational resources for
technology transfer professionals.

## Why OpenTTO?

Technology transfer offices are independently developing many of the same
AI-assisted workflows and automation tools. OpenTTO provides a place for
practitioners to collaborate on those solutions rather than repeatedly
reinventing them at individual institutions.

The project is intended to be institution-neutral and platform-neutral.
Workflows should be adaptable to ChatGPT, Gemini, Copilot, local models,
and other institution-approved technologies.

## What We're Building

### Work
Reusable workflows for technology transfer activities, including:

- Software and open-source release review
- Sponsored research rights analysis
- Sponsor disclosure notices
- Provisional patent application drafting
- Agreement drafting
- Title and waiver analysis
- Other recurring technology transfer workflows

### Learn
A curated collection of:

- Training materials and presentations
- Open-source and software licensing resources
- AI educational resources
- Books, articles, videos, and other references

### Build
Resources for practitioners developing their own systems, including:

- Recommended software and tools
- AI and automation implementation guides
- Local and privacy-conscious AI approaches
- Knowledge-management playbooks
- Platform-specific implementations

## Core Principles

OpenTTO aims to be:

- Open and collaborative
- Institution-neutral
- AI/model-neutral
- Designed by technology transfer practitioners
- Human-in-the-loop
- Security and confidentiality conscious
- Built around reusable and testable workflows
- Never let this work make us replaceable

## Important

Do not contribute confidential, privileged, proprietary, export-controlled,
personally identifiable, unpublished invention, or otherwise restricted
institutional information.

During the initial development phase, examples and test matters should use
synthetic or appropriately public information.

## Status

OpenTTO is currently in its founding and exploratory phase.

The initial repository is private while contributors establish the project's
governance, contribution practices, licensing approach, workflow standard,
and initial reference workflows.
