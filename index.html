THE PROJECT

Build once. Improve together.

Technology transfer offices are independently solving many of the same automation problems. OpenTTO creates a shared place to develop, test, document, and improve those solutions instead of repeatedly reinventing them institution by institution.

HOW WE WORK

Open where appropriate. Controlled where necessary.

OpenTTO is intended to produce openly reusable workflows, software, documentation, and educational resources while maintaining controlled spaces for draft development and practitioner collaboration.

OpenTTO is not a repository for institutional matters. Contributors should never submit confidential, privileged, proprietary, export-controlled, personally identifiable, unpublished invention, or otherwise restricted information. Synthetic or appropriately public materials should be used for shared examples and testing.
